# Бот: новые квартиры и комнаты в Братиславе до 650 €

Каждые 10 минут проверяет сайты и присылает в Telegram только **новые** объявления.

| Сайт | Что ищем |
|---|---|
| reality.bazos.sk: byty | квартиры, радиус 15 км от центра |
| reality.bazos.sk: podnájom | комнаты, подназем, совместное проживание |
| nehnutelnosti.sk | квартиры (reality.sk и byty.sk работают на той же базе, поэтому покрыты тоже) |
| topreality.sk | гарсонки, 1–2-комнатные, апартаменты, Bratislavský kraj |
| bezrealitky.sk | квартиры без агентства; здесь аренда и энергии указаны отдельно, фильтр считает сумму |

В каждом уведомлении есть пометка про энергии: «✅ похоже, с энергиями», «⚠️ похоже, энергии сверху» или «уточнить». Её берём из текста объявления.
Объявления от людей, которые сами ищут жильё («Hľadám byt…»), отсеиваются.

## Запуск

**Быстрый способ (репозиторий уже на GitHub):** в папке проекта выполнить

```bash
./setup.sh
```

Скрипт попросит токен (ввод скрыт), сохранит его в секретах GitHub, попросит нажать Start у бота и запустит проверку. Ниже то же самое вручную.


### 1. Создать бота
1. В Telegram открыть **@BotFather**, отправить `/newbot`, придумать имя и получить токен.
2. Каждый, кто хочет получать уведомления, открывает своего бота и жмёт **Start**.

### 2. Вариант А: бесплатно на GitHub (компьютер можно выключить)
1. Создать **публичный** репозиторий на GitHub и загрузить туда эту папку. В публичном репозитории Actions бесплатны без лимита. Токен туда не попадает, он хранится в секретах.
2. Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN`: токен от BotFather;
   - `TELEGRAM_CHAT_IDS`: chat_id через запятую (как узнать, см. ниже).
3. Вкладка Actions → `check-listings` → **Run workflow**. Первый запуск пришлёт «Бот запущен»; дальше бот проверяет сайты каждые ~10 минут сам.

> GitHub иногда запускает расписание с опозданием на 5–15 минут. Если нужно строго каждые 10 минут, используйте вариант Б.

### 3. Вариант Б: на своём компьютере или сервере
```bash
pip install -r requirements.txt
cp .env.example .env              # вписать TELEGRAM_BOT_TOKEN
python bot.py --chat-id           # покажет chat_id всех, кто нажал Start; вписать в .env
python bot.py --dry-run           # проверить, что сайты парсятся (ничего не отправляет)
python bot.py                     # работать постоянно
```
Подойдёт любой VPS или Railway: команда запуска `python bot.py`. На Mac бот работает, пока ноутбук не уснул.

### Как узнать chat_id без компьютера
Напишите боту что угодно и откройте в браузере
`https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Нужное число в `"chat":{"id": …}`.

### Настройки (`.env` или секреты)
`MAX_PRICE=650`, `CHECK_EVERY_MIN=10`, `BAZOS_RADIUS_KM=15`. С машиной стоит попробовать радиус 25: Senec, Stupava и Pezinok дешевле.

Если какой-то сайт поменяет вёрстку, бот раз в 6 часов пришлёт «⚠️ Не получилось проверить …», а остальные сайты продолжат работать.

## Facebook: что делать вместо парсинга

Автоматически читать группы Facebook нельзя: это нарушает правила, аккаунт быстро банят, и стабильно это не работает. Встроенные уведомления Facebook приходят **быстрее любого парсера**, поэтому делаем так:

1. **Уведомления на все посты в группе.** В приложении: группа → колокольчик / «Уведомления» → **Все публикации**. Каждый новый пост сразу придёт пушем на телефон.
2. **Ещё 4–6 групп.** В поиске Facebook набрать `prenájom Bratislava`, `podnájom Bratislava`, `spolubývanie Bratislava`, `byty Bratislava bez RK`, `izba Bratislava`. Вступить в самые живые (где посты появляются каждый день) и тоже включить «Все публикации».
3. **Marketplace.** Marketplace → Недвижимость / Аренда → Братислава, цена до 650 → **Сохранить поиск** / включить уведомления о новых.
4. **Свой пост «ищу».** Многие сдают без объявлений и просто отвечают на такие посты. Опубликовать во всех группах (текст ниже) и поднимать раз в 2–3 дня.

### Пост в группы (словацкий)
> **Hľadám prenájom v Bratislave od ihneď**: garsónka, 1-izbový byt alebo izba, do 650 € vrátane energií.
> Som [meno], [vek], pracujem ako [práca]. Nefajčiar, bez zvierat, spoľahlivý a čistotný. Zálohu a nájom viem zaplatiť hneď, nasťahovať sa môžem okamžite. Lokalita je flexibilná, mám auto.
> Ďakujem za tipy aj zdieľanie! 📞 [telefón]

### Готовый ответ на объявление (отправлять в первые минуты)
> Dobrý deň, mám vážny záujem o prenájom. Som [meno], pracujem ako [práca], nefajčiar, bez zvierat. Môžem sa nasťahovať ihneď a zálohu zaplatiť hneď pri podpise. Kedy by bola možná obhliadka? Ďakujem, [telefón]

## Как найти быстрее
- **Скорость решает.** Дешёвые варианты в Братиславе уходят за часы. Пришло уведомление: сразу написать готовым текстом, а лучше **позвонить**.
- **Деньги наготове:** обычно это залог + первый месяц, а у агентства ещё и комиссия. Объявления с bezrealitky.sk и с bazos от частников («súkromná osoba») идут без комиссии.
- **Временный вариант на 1–2 месяца.** *Ubytovňa* (общежитие для работников) или комната в подназем часто дешевле квартиры, и заселиться можно в тот же день. Ищите на bazos в разделе podnájom и в Google по запросу `ubytovňa Bratislava mesačne`. Это лучше, чем жить в машине, а квартиру можно спокойно искать дальше.
- **Документы на одной странице:** паспорт, справка о работе или доход. Отправлять арендодателю сразу, без вопросов.
